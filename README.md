# MotoMoto Company

Proyecto MotoMoto basado en la plataforma de FoodXpres y adaptado con la identidad visual de MotoMoto.

## Aplicaciones

- `apps/web-clientes`: experiencia de clientes.
- `apps/web-admin`: panel administrativo.
- `apps/web-local`: herramientas para locales.
- `apps/web-driver`: herramientas para repartidores.
- `packages`: componentes y configuración compartidos.

## Desarrollo

Requiere Node.js 20 o superior y pnpm 9.

```bash
pnpm install
pnpm dev
```

Configura tus archivos `.env.local` en cada aplicación antes de iniciar los servicios.
